info CSV Import Instructions

Please read carefully before preparing your CSV file for import.

1
Required Fields:

Your CSV file MUST contain Official ID and Full Name. Other columns are optional.

2
Automatic Mapping:

Headers are matched case-insensitively. Feel free to use headers like "Official ID", "Full Name", "Mobile", "Email", "Status", or their SQL column counterparts.

3
Upsert Logic:

If the Official ID already exists, the record will be updated. If it does not exist, a new record will be created.

4
Date Formats:

Dates should be formatted as YYYY-MM-DD. However, common formats like DD-MM-YYYY, DD/MM/YYYY, or MM/DD/YYYY are parsed automatically.

5
Status Values:

Set the status as ACTIVE, PROBATIONARY, or INACTIVE.

6
Import Limits:

CSV files must be under 2MB in size and contain a maximum of 1,000 rows.

7
Excel Direct Copy-Paste:

Switch to the "Paste Raw Data" tab, copy the cells from Excel/Google Sheets (with headers), and paste them directly into the text box.
